# PianomanuelHub (iOS stub)

Week of 14 Sep 2026. Wrapper only. No App Store upload. No Sign in with Apple.

## Open in Xcode

1. Xcode → File → New → Project → App (SwiftUI, iOS).
2. Product Name `PianomanuelHub`. Bundle ID `com.pianomanuel.hub`.
3. Replace the generated `PianomanuelHubApp.swift` / `ContentView.swift` with the files in this folder.
4. Drag the repo `site/` folder into the Xcode project. Check “Create folder references” so `site/index.html` is in the bundle.
5. Run on a simulator or your phone. It should show the window page from the bundle.

Do not enable Associated Domains until PUBLIC_DNS is allowed. Team ID stays in Keychain, not in this repo.
